# Revisions Statuses (Pro)

This feature requires the Pro version of the PublishPress Revisions plugin.

This feature requires the Pro version of the PublishPress Statuses plugin.

The Pro version of [PublishPress Statuses](https://publishpress.com/links/statuses) offers the ability to create statuses for revisions created with the Pro version of the [PublishPress Revisions](https://publishpress.com/links/revisions) Pro. After installing both plugins, you will see a tab extra labelled “Revision”, shown in the screenshot below.

The [PublishPress Revisions](https://publishpress.com/links/revisions) plugin allows you to submit changes to existing posts on your site. This [PublishPress Statuses](https://publishpress.com/links/statuses) feature allows you to process those changes through a workflow before they are published.

![Revision statuses](https://docs-media.publishpress.com/publishpress-statuses/revision-statuses-1-6c1e43c1e1.webp)

These statuses have the same features as other statuses in the PublishPress Revisions plugin:

- **Name**: Choose the name, color, and icon for the status.
- **Labels**: Select the labels that are used for this status when editing a revision.
- **Post Types**: Choose which post types this status will apply to.
- **Roles**: Select which user roles can assign this status to a post.
- **Post Access**: This gives you detailed control over who can edit and delete content in this status.

These statuses will appear in the post editor when you are working on a revision. Click the “Workflow” button as shown in this screenshot:

![Workflow revisions](https://docs-media.publishpress.com/publishpress-statuses/workflow-button-f488ce250f.webp)

You will then be given a choice of which status to move this revision to, as in this next screenshot:

![Workflow with revisions](https://docs-media.publishpress.com/publishpress-statuses/workflow-publish-1-dca77685a3.webp)

These statuses will be labelled on the “Revisions Queue” screen. In this screenshot below you can see the “Status” column is reflecting the custom statuses.

![Revisions queue statuses](https://docs-media.publishpress.com/publishpress-statuses/revisions-queue-statuses-1-e9300b91cb.webp)

It’s now possible to combine the PublishPress Revisions and [PublishPress Planner](https://publishpress.com/links/planner) plugins.

In the Revisions plugin, you can [schedule revisions to be automatically published in the future](https://publishpress.com/knowledge-base/schedule-revision-future/). This allows you to update content now, but publish those changes at a later date.

In the Planner plugin, you can use [the Content Calendar screen](https://publishpress.com/knowledge-base/content-calendar/) to see all your planned content.

You can see all your [scheduled revisions](https://publishpress.com/links/scheduled-revisions) on the [Content Calendar](https://publishpress.com/links/content-calendar) screen. If you’re using the Pro version of [PublishPress Planner](https://publishpress.com/links/planner), you’ll see the “Show Revisions” button in the screenshot below.

![Show Revisions on Calendar](https://docs-media.publishpress.com/publishpress-statuses/show-revisions-76daf2a23c.webp)

After you click the “Show Revisions” button, you’ll be able to see all your [scheduled revisions](https://publishpress.com/links/scheduled-revisions), as in this screenshot below:

![Schedule revisions on Content Calendar](https://docs-media.publishpress.com/publishpress-statuses/revisions-calendar-59456b25b2.webp)

This approach also works for the [Content Overview](https://publishpress.com/knowledge-base/the-content-overview-screen/) and [Content Board](https://publishpress.com/knowledge-base/the-content-board-screen/) screens. This next screen shows how to view revisions on the [Content Overview](https://publishpress.com/links/content-overview) screen:

![Content Overview revisions](https://docs-media.publishpress.com/publishpress-statuses/content-overview-revisions-499eec1c71.webp)

This next screen shows how to view revisions on the [Content Board](https://publishpress.com/links/content-board) screen. If you click “Show Revisions”, only the revision statuses will be shown.

![Content Board Revisions](https://docs-media.publishpress.com/publishpress-statuses/revision-content-board-1f4b704789.webp)
