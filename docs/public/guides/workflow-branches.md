# Workflow Branches

The [PublishPress Statuses](https://publishpress.com/links/statuses) plugin allows you to create workflow branches. These are separate parts of the workflow are displayed shown as indented, away from the main workflow. These branches be used to take content away from the core approval process.

You can create workflow branches with any statuses except for “Draft” and “Pending Review” which are core WordPress statuses.

To create workflow branches, use the drag-and-drop handles next to each status to place them into branches

![Workflow branches](https://docs-media.publishpress.com/publishpress-statuses/branch-workflows-0fd573cca9.webp)

The workflow branches will be indented when you’re using the “Post Status” dropdown in the post editing screen. This screenshot below shows how the posts are indented.

![Workflow branches in the editing screen](https://docs-media.publishpress.com/publishpress-statuses/branched-workflow-790f35fc20.webp)

If you are not able to see the workflow branches, go to the “Settings” area in [PublishPress Statuses](https://publishpress.com/links/statuses). Look for the “Sub-Status Selection” option. When enabled, this will hide workflow branches unless the post is currently inside that workflow branch.

![Hide nested statuses](https://docs-media.publishpress.com/publishpress-statuses/hide-nested-statuses-841d0f145f.webp)
