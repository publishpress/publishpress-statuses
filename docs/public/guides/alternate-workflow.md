# Alternate Workflow for Pre-Publication Statuses

The [PublishPress Statuses](https://publishpress.com/links/statuses) plugin has a feature called the “Alternate Workflow”. This feature is for statuses that are optional and not required.

The “[Main Workflow](https://publishpress.com/knowledge-base/main-workflow/)” must be used for all posts and contains the “Draft” and “Pending Review” statuses.

The “Alternate Workflow” contains statuses are that optional. This is used for statuses that do not lead to publication. Example statuses include “Needs Work”, “Rejected” and “Deferred”.

The “Alternate Workflow” statuses will only appear in the dropdown in the post editing screen. They will always appear below the statuses in the “Main Workflow”.
