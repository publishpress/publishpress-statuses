# Custom Visibility Statuses (Pro)

Table of Contents

- [Core WordPress Visibility Statuses](#h-core-wordpress-visibility-statuses)
- [How to Use Visibility Statuses](#h-how-to-use-visibility-statuses)
- [How to Create New Visibility Statuses](#h-how-to-create-new-visibility-statuses)

This feature requires the Pro version of the PublishPress Permissions plugin.

Visibility Statuses control who can access published content on your WordPress site.

The [PublishPress Statuses](https://publishpress.com/links/statuses) plugin integrates with the Pro version of the [PublishPress Permissions](https://publishpress.com/links/permissions). This integration allows you to create custom visibility statuses and control who can access the content on the front of your WordPress site.

## Core WordPress Visibility Statuses [#](#h-core-wordpress-visibility-statuses)

We call this feature “Custom Visibility Statuses” because WordPress has three core visibility statuses:

- [Scheduled](https://publishpress.com/knowledge-base/future/): This post is scheduled for future publication.
- [Published](https://publishpress.com/knowledge-base/publish/): This post is available to general public.
- [Private](https://publishpress.com/knowledge-base/private/): This post is published for users logged in to your WordPress site.

You can see these three core statuses on the “Visibility Statuses” screen, as in this screenshot below:

![](https://docs-media.publishpress.com/publishpress-statuses/visibility-statuses-1-919eb99356.webp)

## How to Use Visibility Statuses [#](#h-how-to-use-visibility-statuses)

You can enable this feature via the “Settings” area in the [PublishPress Permissions](https://publishpress.com/links/permissions) plugin and the “Statuses” tab:

![Enable Visibility Statuses](https://docs-media.publishpress.com/publishpress-statuses/enable-visibility-statuses-c8ae574cef.webp)

Go to “Statuses” and then “Visibility” and you’ll see the visibility statuses.

![Visibility statuses](https://docs-media.publishpress.com/publishpress-statuses/visibility-statuses-c1758e434f.webp)

These statuses will now be available when you’re editing a published post. In this screenshot below, “Published” has been replaced by several different visibility statuses, including “Public”, “Private”, “Member”, “Premium”, and “Staff”.

![Custom visibility statuses](https://docs-media.publishpress.com/publishpress-statuses/visibility-statuses-give-access-11bbe5022a.webp)

## How to Create New Visibility Statuses [#](#h-how-to-create-new-visibility-statuses)

With the [PublishPress Permissions Pro](https://publishpress.com/links/permissions) plugin enabled, you can create new Visibility Statuses.

- Go to “Permissions” then “Settings”.
- Click the “Statuses” tab and check the box labeled Custom Visibility Statuses”.

![Enable visibility statuses](https://docs-media.publishpress.com/publishpress-statuses/enable-custom-9e66bf8913.webp)

- You will now be able to visit the main “Statuses” screen and click the “Add New” button.

![Add new visibility statuses](https://docs-media.publishpress.com/publishpress-statuses/new-visilbilty-statuses-394440adb5.webp)
