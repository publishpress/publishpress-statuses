# Different Statuses for Different Post Types

It is possible to have different statuses for different WordPress post types. The benefit of this approach is that allows you have different workflows for each post type.

- Go to “Statuses”.
- Click the link to edit any status.
- Click the “Post Types” tab.
- Uncheck the “All Post Types” box and you can choose which post types will be connected to this status.

![Post types tab](https://docs-media.publishpress.com/publishpress-statuses/post-types-tab-555262c257.webp)

*Edit Post Status*

Following the example above, this status will now be available in the “Post Status” dropdown when you create new Pages. This statuses will not be available when you create new Posts.
