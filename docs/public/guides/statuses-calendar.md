# Statuses and the Planner Calendar

The [PublishPress Statuses](https://publishpress.com/links/statuses) plugin integrates with the [PublishPress Planner](https://publishpress.com/links/planner) plugin. This allows you to use custom statuses, icons, and colors on the “[Content Calendar](https://publishpress.com/links/content-calendar)” screen. In the screenshot below you can see posts with different statuses:

- The post with a brown background is in the “In Progress” status.
- The post with the orange background is in the “Pending Review” status.
- The posts with the green background are in the “Published” status.
- The posts with the purple background are in the “Scheduled” status.

![Content Calendar with statuses](https://docs-media.publishpress.com/publishpress-statuses/planner-statuses-d45bcea56d.webp)

You can customize these statuses, icons, and colors by going to the “Statuses” screen in [PublishPress Statuses](https://publishpress.com/links/statuses). This screenshot below shows how you can edit the “Pending Review” statuses to use a different color and different icon. Those changes will be reflected on the “[Content Calendar](https://publishpress.com/links/content-calendar)” screen.

![Pending review status edit](https://docs-media.publishpress.com/publishpress-statuses/change-pending-review-287a85dda8.webp)
