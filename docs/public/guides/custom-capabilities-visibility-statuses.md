# Custom Capabilities for Visibility Statuses (Pro)

Table of Contents

- [Control Who Can Read Content in a Status](#h-control-who-can-read-content-in-a-status)
- [Control Who Can Edit and Delete Content in a Status](#h-control-who-can-edit-and-delete-content-in-a-status)

This feature requires the Pro version of the PublishPress Permissions plugin.

This feature requires the Pro version of the PublishPress Capabilities plugin.

The [PublishPress Statuses](https://publishpress.com/links/statuses) plugin integrates with the [PublishPress Permissions Pro](https://publishpress.com/links/permissions) plugins and [PublishPress Capabilities Pro](https://publishpress.com/capabilities/) plugins. These allow you to control capabilities for each visibility status. You can decide who can assign, read, edit and delete content in each status.

## Control Who Can Read Content in a Status [#](#h-control-who-can-read-content-in-a-status)

If you install the [PublishPress Permissions Pro](https://publishpress.com/links/permissions) plugin along with [PublishPress Statuses](https://publishpress.com/links/statuses), you can control who can read content in each status.

- Go to “Statuses” and click the “Post Access” tab.
- Click the status you want to edit and then the “Post Access”.

You will now be able to choose to capabilities for each user role:

- **Set**: Users in this role can move posts to this status.
- **Read**: Users in this role can move posts to this status.

![Edit Post Access for a visibility status](https://docs-media.publishpress.com/publishpress-statuses/post-access-visibility-2710f4e94b.webp)

It is also possible to control these statuses via the “Groups” screen in [PublishPress Permissions](https://publishpress.com/links/permissions):

- Go to “Permissions” and then “Groups”.
- Click on the role or group you want to edit.
- Click the “Set Specific Permissions” tab.
- For each post type, you can choose the “Post Visibility” option under “Qualification”. This allows you to choose detailed permissions for how these users interact with this post visibility status.

![Set specific group permissions for statuses](https://docs-media.publishpress.com/publishpress-statuses/groups-visibility-8bbea6d208.webp)

## Control Who Can Edit and Delete Content in a Status [#](#h-control-who-can-edit-and-delete-content-in-a-status)

If you install the [PublishPress Permissions Pro](https://publishpress.com/links/permissions) and [PublishPress Capabilities Pro](https://publishpress.com/capabilities/) plugins along with PublishPress Statuses, you can get more detailed control over content in each status.

- Go to “Capabilities”, then “Settings”.
- Click the “Capabilities” tab and enable “Apply status-specific, type-specific editing capabilities for Visibility Statuses”.

![Enable custom capabilities for statuses](https://docs-media.publishpress.com/publishpress-statuses/visibility-statuses-apply-a8cb73aed3.webp)

- Go to “Statuses” and click the “Post Access” tab.
- Click the status you want to edit and then the “Post Access”.

You will now be able to choose to capabilities for each user role:

- **Set**: Users in this role can move posts to this status.
- **Read**: Users in this role can move posts to this status.
- **Edit Others**: Edit content written by other users in this status.
- **Delete Others**: Delete content written by other users in this status.

![Custom statuses capabilities](https://docs-media.publishpress.com/publishpress-statuses/statuses-custom-caps-c910e16f99.webp)

If it also possible to make these changes inside the main “Capabilities” screen of the [PublishPress Capabilities](https://publishpress.com/links/capabilities) plugin. Click the “Custom Visibility” tab and you’ll be able to control all the statuses on one screen, as in this screenshot below:

![Custom visibility statuses in PublishPress Capabilities](https://docs-media.publishpress.com/publishpress-statuses/capabilities-custom-visibility-3590c9e7a0.webp)
