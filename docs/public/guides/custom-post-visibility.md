# Examples of Visibility Statuses (Pro)

This feature requires the Pro version of the PublishPress Permissions plugin.

With [PublishPress Permissions Pro](https://publishpress.com/permissions/), you can create Custom Visibility Statuses for your content.

One example is a “Premium” status that makes content visible only for paying members. Another example is a “Staff” status, for the people who run your site.

- Go to “Statuses” in your WordPress admin menu.
- Click the “Visibility” tab.
- You will see that “Member”, “Premium” and “Staff” are available by default.

![Custom Visibility statuses](https://docs-media.publishpress.com/publishpress-statuses/member-premium-staff-67cbd3883b.webp)

Click on “Member” and you’ll be able to change the name of this status, and which post types it applies to:

![](https://docs-media.publishpress.com/publishpress-statuses/member-status-40277a0978.webp)

These statuses are available when you are writing a post. This “Visibility” dropdown allows you to choose a status:

![](https://docs-media.publishpress.com/publishpress-statuses/privacy-status-gutenberg-023de94375.webp)

You can control who has access to these statuses by using [the Groups feature](https://publishpress.com/knowledge-base/groups/) in [PublishPress Permissions](https://publishpress.com/links/permissions).

- Go to Permissions > Groups in your WordPress admin menu.
- Click “edit” for one of the groups. In the image below, I’m doing that for Authors:

![](https://docs-media.publishpress.com/publishpress-statuses/authors-workflow-status-9eb09f9b56.webp)

You can now add give Authors extra permissions. In the image below, I’m allow Authors to act as “Editors” for posts with the “Pending” status. This means the Authors will be able to edit any posts with this status.

![](https://docs-media.publishpress.com/publishpress-statuses/author-pending-93da54cc33.webp)
